# founder-story-slides

Browser-based slide deck for Aram Shakhbandaryan.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Controls

- `→` / `Space`: next slide
- `←`: previous slide
- swipe on mobile

## Files

- `index.html` — deck markup
- `styles.css` — visual system and responsive layout
- `script.js` — slide navigation
- `assets/aram-beach.jpg` — founder photo
